# Sincronização Automática com o GitHub

Ao finalizar a execução de qualquer prompt ou solicitação do usuário:
1. Execute `npm run build` se houver mudanças em arquivos de frontend/código.
2. Adicione as mudanças com `git add .`.
3. Faça o commit com mensagem descritiva (Conventional Commits).
4. Realize o envio imediato para o GitHub com `git push`.
5. Confirme o envio ao GitHub na resposta final.
